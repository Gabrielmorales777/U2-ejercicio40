# U2-ejercicio40
### Sistema de Conversión de Divisas

**Objetivo principal:** Desarrollar un sistema modular en Java que permita convertir montos monetarios entre diferentes monedas utilizando distintas fuentes de cotización.

Se implementa una clase abstracta `ProveedorTasaCambio` y dos clases concretas (`TasaBancoCentral` y `TasaMercadoLibre`), cada una con sus propias tasas de cambio simuladas. Además, se desarrolla la clase `ConversorMoneda`, encargada de realizar las conversiones utilizando el proveedor seleccionado.

El ejercicio aplica **abstracción, herencia, polimorfismo, sobrescritura de métodos, encapsulamiento y asociación entre clases**, permitiendo intercambiar las fuentes de cotización sin modificar la lógica principal del conversor.
